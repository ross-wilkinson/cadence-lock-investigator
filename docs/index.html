Sampling Rate & Coverage

The headline figure is each device's measured median HR sampling rate — an observation, with no assumed standard behind it. The delivered share beneath it is measured against 1 Hz, an assumed common baseline chosen so all three devices are judged on one yardstick; it is not any manufacturer's advertised rate, as neither Garmin nor Polar publish a real optical/ECG HR sampling-rate spec. The two numbers answer different questions and can diverge sharply: a device reading a full 1 Hz whenever it samples at all, but dropping out for half the run, shows 1 Hz alongside a 50% share — and that gap is the dropout.

Effort Context for Suspected Runs

Every number in this dashboard covers 3-way runs only (a wrist device plus a Polar H10 chest-strap reference); 2-way runs are excluded from all of it and appear only in the Activity Log below. Which runs count as suspect is still bounded by manual per-run review, not an automated per-instant detector, which doesn't exist yet. Effort context is split into walking vs. running using an 8:00 min/km pace threshold (8:00/km or slower counts as walking, faster counts as running) applied to each device's own worst-disagreement pace bucket, and “most common true HR” is the Polar H10's own recorded mean HR in that bucket.
